About us

Two patents covering the PWA and XR runtime — software testing is in progress ahead of release.

CN115729614A

Progressive Web App standard-based runtime library, data interaction method, device and medium. Registered at patents.google.com and cponline.cnipa.gov.cn.

CN116954824A

A runtime system, data interaction method, device, and media that provides a multiple-process environment to execute various extended reality (XR) specification based applications and 2D applications.

The pwaos team builds the runtime, the shell, the browser, the appstore and the developer SDK. Find the project on GitHub or try the demo.
